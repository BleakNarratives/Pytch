# Pytch

**Outreach automation — pitch generation, deployment, and follow-up.**

Pytch is the outreach engine for the MikeySwarm ecosystem. It generates personalized pitches, deploys them across channels, and tracks follow-up sequences. Built as a sub-agent of Spindle.

---

## Quick Start

```bash
python pytch.py --help
```

## Features

- **Pitch generation** — AI-powered personalized outreach messages
- **Multi-channel deployment** — email, social, direct
- **Follow-up sequences** — automated drip campaigns
- **Response tracking** — open rates, replies, conversions

## Structure

```
pytch.py                 Main entry point
pytch_wrapper_campaigns.py   Campaign orchestration
pytch/                   Core modules
docs/                    Documentation
exports/                 Generated pitch files
```

## Dependencies

No external packages required — stdlib only.
